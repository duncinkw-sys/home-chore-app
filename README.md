# Home Chore App

A simple app to track and manage household chores.

## Features

- Add and remove chores
- Assign chores to family members
- Track completion status
- Weekly chore rotation

## Getting Started

1. Open `index.html` in your browser
2. Add your family members
3. Start adding chores!
